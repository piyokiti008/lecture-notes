  • 自分でまとめを書かなくても、要点は自動で集まります

  • どの配色でも、印刷は白い紙・黒い文字です

PowerPoint・PDF・Word・画像・テキスト、そして音声ファイルも読み込めます。AI が要点を整理して、このアプリの書き方でノートの下書きを作ります。保存する前に、必ず自分で確認できます。

AI は、ご自身の API キー（Gemini は無料枠あり）か、パソコンにインストールする Ollama で動かします。料金はかかりません。Gemini の無料枠では、送った内容が Google の改善に使われることがあります。

講義ノートについて

大学の講義を、教科・単元ごとに書きためて、考査の前には範囲を選ぶだけで「まとめ」や「練習問題」のプリントにできるノートです。

書くだけで整理教科と単元に分けて、講義メモを書きためます。==重要== {{穴埋め}} 用語 :: 説明 Q:/A: の印をつけるだけで、あとから集められます。
考査前はプリントに範囲の単元を選ぶと、まとめ・穴埋め・一問一答・用語テストのプリントができます。そのまま印刷や PDF 保存ができます。
どの端末でも続きからGoogle でログインすると、ノートがあなた自身の Google ドライブに自動で保存されます。パソコンでもスマホでも、同じノートを開けます。

さっそく、使ってみましょう。どちらで使いますか？

どちらかを選ぶと、Google のログイン画面が開きます。あとから「メニュー」の設定で、いつでも切り替えられます。

運営（このアプリの作者）に見えるもの：ログインしたアカウントの一覧（メールアドレス・名前）だけです。
運営に見えないもの：ノートの中身。ノートはあなた自身の Google ドライブに保存され、運営は読めません。
このアプリが使う権限は「このアプリが作ったファイルだけ」で、ドライブの他のファイルには触れません。

（ノートは、この端末のブラウザの中だけに保存されます）
